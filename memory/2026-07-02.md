This caused a server-side roundtrip delay of **1.0 to 1.5 seconds**, inflating the Time to First Byte (TTFB). Refactored [middleware.ts](file:///C:/Users/User/Desktop/agenc-ia/apps/getxobelaeskola-web/src/middleware.ts) to bypass these database auth checks for static public landing pages, allowing Vercel to respond instantly and slash LCP delays.
  - **Mobile LCP Preloading:** Added layout-level preloads for `cloud_only_mini.webp` and `cloud_sun_mini.webp` in [layout.tsx](file:///C:/Users/User/Desktop/agenc-ia/apps/getxobelaeskola-web/src/app/[locale]/layout.tsx) and set `fetchPriority="high"` inside [Navbar.tsx](file:///C:/Users/User/Desktop/agenc-ia/apps/getxobelaeskola-web/src/components/layout/Navbar.tsx) to ensure header clouds (which the browser identifies as mobile LCP targets due to responsive sizing) load at 0ms. Added native `style={{ opacity: 0.95 }}` inline override to the cloud element to ensure it paints immediately on FCP rather than waiting for client-side Framer Motion hydration.
  - **Vercel Analytics & Speed Insights:** Installed `@vercel/analytics` and `@vercel/speed-insights` and integrated them into [layout.tsx](file:///C:/Users/User/Desktop/agenc-ia/apps/getxobelaeskola-web/src/app/[locale]/layout.tsx) to track production load performance and real-user metrics.
