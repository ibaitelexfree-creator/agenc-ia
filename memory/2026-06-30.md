# Memory - 2026-06-30

- Resolved a critical payment checkout bug that caused a "Failed to fetch" error on the production website (`https://getxobelaeskola.cloud`).
- The root cause was that `getApiBaseUrl()` in `src/lib/api.ts` always returned `process.env.NEXT_PUBLIC_APP_URL` if it was set. During build-time/local-dev, this environment variable is configured to `http://localhost:3000`. Consequently, in the production browser environment, calls to `apiUrl('/api/checkout')` were resolving to `http://localhost:3000/api/checkout`, resulting in connection failure and the browser throwing a `Failed to fetch` error.
- Modified `getApiBaseUrl` in [api.ts](file:///C:/Users/User/Desktop/agenc-ia/apps/getxobelaeskola-web/src/lib/api.ts) to check if `NEXT_PUBLIC_APP_URL` is a local address (containing `localhost` or `127.0.0.1`). If the client is running on a non-localhost domain in a web browser, it now ignores the local address and correctly falls back to the production URL, resolving checkout requests to the correct host.
