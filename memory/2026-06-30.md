# Memory - 2026-06-30

- Resolved a critical payment checkout bug that caused a "Failed to fetch" error on the production website (`https://getxobelaeskola.cloud`).
- The root cause was twofold:
  1. `getApiBaseUrl()` in `src/lib/api.ts` returned `process.env.NEXT_PUBLIC_APP_URL` (`http://localhost:3000`) compiled in the client-side bundle, resolving APIs to localhost.
  2. Even after bypassing localhost, the fallback was hardcoded to `https://getxobelaeskola.cloud` (non-www). When users accessed the site via `https://www.getxobelaeskola.cloud` (with www), the API call turned into a cross-origin request. The server's 308 Permanent Redirect to the www domain was then blocked by the browser's CORS policy, resulting in `Failed to fetch`.
- Modified `getApiBaseUrl` in [api.ts](file:///C:/Users/User/Desktop/agenc-ia/apps/getxobelaeskola-web/src/lib/api.ts) to:
  - Ignore local address values in `NEXT_PUBLIC_APP_URL` on standard production domains.
  - Fall back to the active `window.location.origin` instead of a hardcoded non-www URL when in a standard web browser (non-Capacitor), matching whatever hostname the user is currently browsing (with or without `www.`) and eliminating CORS redirect errors.
