# Memory - 2026-07-01

- Resolved multiple issues found in Desktop & Mobile PageSpeed Insights reports for `https://www.getxobelaeskola.cloud/`:
  - **Performance:** Optimized heavy hero images (`velero.webp` and `tierra.webp`) using `ffmpeg` by compressing/scaling them to 1920px width (saving ~75% space). Converted cloud PNG assets to WebP (saving >90% space). Added responsive `sizes` attribute descriptors to logo images in the navigation bar. Parallelized parallax layer image loading in `Section1Hero.tsx` by removing sequential `onLoad` conditional render blocks. Implemented HTML image preloads in `page.tsx` (Server Component entry) to guarantee hoisting inside the document `<head>` during SSR, and encoded spaces to `%20` inside the sky image filename to ensure browser preload matching. Restricted the heavy drifting clouds video to client-side desktop-only (`mounted && !isMobile`), completely removing its 1.35 MB payload on mobile devices and avoiding network starvation. Removed programmatic page-load intro scroll on mount in `useScrollEngineV2.ts` to prevent layout shifts. Exported `generateStaticParams` in `page.tsx` to statically pre-render landing page segments at build time, reducing Time to First Byte (TTFB) from ~1s to <50ms.
  - **Card Video Lazy-Loading:** Refactored `BlobCard.tsx` to lazy-load hover videos only when hovered (desktop) and completely disabled them on mobile viewports. This prevents loading video payloads on scroll/crawl events, saving **3.7 Megabytes** of network payloads.
  - **Accessibility:** Corrected contrast issues on skip-link by enforcing high-contrast dark text (`#1A1A1A`). Changed newsletter submit button background from accent orange to nautical blue (`bg-nautical-blue`) with white text, raising the contrast ratio to **10.5:1** (fully compliant with AA/AAA standards). Reached a perfect **100/100** Accessibility score! Added `aria-label` tags to the Decathlon link, mobile menu toggle, and submenu expand/collapse toggle buttons. Embedded empty data-URI VTT caption tracks in background video elements.
  - **Best Practices:** Resolved console CORS fetch failures on `/api/weather` under the `www` subdomain by making `getApiBaseUrl` fall back early to `window.location.origin` in all browser clients.
  - **SVG Path Warnings:** Migrated keyframe animations inside `BlobCard.tsx` to native GPU-driven SVG `<animate>` tags. This resolves a Framer Motion bug where it failed to query non-rendered attributes inside `<defs>`/`<clipPath>` on mount (which threw 15 `Expected moveto path command` console errors).
  - **SEO & Agentic Browsing:** Formatted generated canonical URLs in `seo.ts` to use `www.getxobelaeskola.cloud` matching the main site. Created a valid `llms.txt` file inside the public directory and updated the root `.gitignore` file to track `llms.txt`, ensuring it is deployed to Vercel and successfully indexed. Cleared all Agentic audits (3/3).
