# Memory - 2026-07-01

- Resolved multiple issues found in Desktop & Mobile PageSpeed Insights reports for `https://www.getxobelaeskola.cloud/`:
  - **Performance:** Optimized heavy hero images (`velero.webp` and `tierra.webp`) using `ffmpeg` by compressing/scaling them to 1920px width (saving ~75% space). Converted cloud PNG assets to WebP (saving >90% space). Added responsive `sizes` attribute descriptors to logo images in the navigation bar to prevent loading large images on smaller displays.
  - **Card Video Lazy-Loading:** Refactored `BlobCard.tsx` to lazy-load hover videos only when hovered (desktop) or when in view (mobile), and decoupled the card reveal from the video load state. This completely avoids downloading **3.7 Megabytes** of video data on page load, dramatically boosting page speed performance.
  - **Accessibility:** Corrected contrast issues on skip-link by enforcing high-contrast dark text (`#1A1A1A`). Changed newsletter submit button text to white (`#FFFFFF`) to ensure AAA compliance (contrast ratio of 4.62:1 against the buoy-orange background). Added `aria-label` tags to the Decathlon link, mobile menu toggle, and submenu expand/collapse toggle buttons. Embedded empty data-URI VTT caption tracks in background video elements.
  - **Best Practices:** Resolved console CORS fetch failures on `/api/weather` under the `www` subdomain by making `getApiBaseUrl` fall back early to `window.location.origin` in all browser clients.
  - **SVG Path Warnings:** Added fallback coordinates `d0, d1, d2` inside `BlobCard.tsx` to eliminate dynamic SVG path warnings in the console due to uninitialized props during SSR or hydration.
  - **SEO & Agentic Browsing:** Formatted generated canonical URLs in `seo.ts` to use `www.getxobelaeskola.cloud` matching the main site. Created a valid `llms.txt` file inside the public directory and updated the root `.gitignore` file to track `llms.txt`, ensuring it is deployed to Vercel and successfully indexed.
