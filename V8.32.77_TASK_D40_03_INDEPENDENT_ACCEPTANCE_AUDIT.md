## 4. JSON Schema Adversarial Review

### 4.1 Specification Compliance & Schema Mechanics
- **Draft Standard:** Both `pilot-request-schema.json` and `pilot-response-schema.json` declare `$schema: "https://json-schema.org/draft/2020-12/schema"`.
- **Compiler Implementation:** `pilot-validator.js` initializes `Ajv2020` (`ajv/dist/2020.js`) and attaches `addFormats(ajv)`. Tested directly with Node.js 24: both schemas compile cleanly without warnings.
- **`additionalProperties: false`:** Declared at root and nested levels (`messages.items` in request, root in response). Probed with injected properties (`unauthorized_injected_field`, `messages[0].extraProp`); all were rejected with `INVALID_REQUEST`.
- **String Formats & Constraints:**
  - `task_id` & `agent_id`: Regex `^[A-Za-z0-9_\-\.]{3,64}$`. Empty strings, spaces, symbols (`@`, `/`), and strings `< 3` or `> 64` chars are rejected.
  - `request_id`: Regex `^[A-Za-z0-9_\-]{8,64}$`. Validated to prevent short or unbounded correlation keys.
  - `execution_timestamp`: `"format": "date-time"`. Tested invalid date formats (e.g., `'invalid-time'`, `'not-a-date'`); all rejected.
- **Mutual Exclusivity:**
  `pilot-response-schema.json` utilizes `allOf` with `if / then / else` blocks on `status == "SUCCESS"`.
  - Tested: `status: "SUCCESS"` with `result: null` -> **REJECTED**.
  - Tested: `status: "SUCCESS"` with `error: { ... }` -> **REJECTED**.
  - Tested: `status: "TIMEOUT"` with `result: { ... }` -> **REJECTED**.
  - Tested: `status: "TIMEOUT"` with `error: null` -> **REJECTED**.

### 4.2 Adversarial Edge Conditions Tested

1. **Null Values:** Sending `null` for `task_id`, `agent_id`, `messages`, or `output_schema_version` fails schema validation (`INVALID_REQUEST`).
2. **Empty Arrays / Strings:** Sending `messages: []` or `content: ""` fails schema validation.
3. **Payload Bloat:** Sending `content` exceeding 8,192 chars in a single message fails schema validation (`maxLength`). Sending multi-message payloads totaling > 8192 chars passes schema but is caught and rejected by JavaScript validator (`validatePilotRequest()`).
4. **Model Alias Exploit:** Attempting to submit `model: "local-model"` to bypass loaded-model checks is intercepted at `pilot-validator.js:46` and rejected with `MODEL_UNAVAILABLE`.
